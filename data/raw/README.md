# YouTube-videos-Analysis
Repistorio dedidacado al proyecto de investigación: "Análisis de la similitud de países en base a su co-consumo de videos populares en YouTube", desarrollado para el curso Laboratorio III.

Se trabajan con un set de datos de videos más pupulares de youtube en 11 países, obtenidos de Kaggle: https://www.kaggle.com/datasets/rsrishav/youtube-trending-video-dataset.
